## Temporal masking

- Default: **disabled in every shipped profile**
- Reason: temporal_mask zeroes whole frames, which is ambiguous with the missing-hand / padding encoding in the 126-dim contract
- Re-enabling requires: a frame-validity channel in the model input contract
- Debug override: `--aug_set temporal_mask_probability=<p>`

The `temporal` profile therefore contains only temporal roll, which reorders existing frames and cannot create a dead frame or a frame that is ambiguous with padding or with a missing hand.
