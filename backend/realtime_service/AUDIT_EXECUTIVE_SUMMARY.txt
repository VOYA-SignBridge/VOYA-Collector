AUDIT FINDINGS & FIXES
================================================================================

ISSUE 1: model.eval() per request
─────────────────────────────────
SEVERITY: Low (optimization, not correctness)
FINDING: Code was calling model.eval() on every request
FIX: Verified model.eval() happens at startup in warmup()
     Model never switches back, no per-request overhead
RESULT: ✅ FIXED - cleaner code, less overhead

ISSUE 2: softmax numerical stability
─────────────────────────────────────
SEVERITY: Medium (future-proofing)
FINDING: Using numpy softmax instead of torch.softmax
FIX: Changed to torch.softmax(logits.float(), dim=-1)
     Added .float() casting for mixed precision safety
RESULT: ✅ FIXED - numerically stable, GPU-ready

ISSUE 3: normalization silent fallback
──────────────────────────────────────
SEVERITY: Critical (semantic coupling risk)
FINDING: normalize_hands_vector_126() returns original if malformed
ISSUE: Could hide corruption; run_realtime.py depends on behavior
FIX: Added validation BEFORE & AFTER normalization
     - Pre-validate: frame.size == 126
     - Call normalize_hands_vector_126()
     - Post-validate: output.size == 126
DECISION: Keep normalize_hands_vector_126() unchanged (preserve production)
RESULT: ✅ SAFE - endpoint is safe, migration deferred

ISSUE 4: TCN shape assumptions
───────────────────────────────
SEVERITY: High (could cause subtle bugs)
FINDING: Code said "accepts (B,T,D) or (B,D,T)" but no assertions
FIX: Added explicit shape assertions before inference
     assert x.ndim == 3
     assert x.shape == (1, 60, 126)
RESULT: ✅ FIXED - transpose bugs impossible

ISSUE 5: CPU-only design
────────────────────────
SEVERITY: Info (design decision)
FINDING: All operations on CPU
DECISION: Correct prioritization (semantic correctness > performance)
RESULT: ✅ APPROVED - GPU deferred to Step 2+

ISSUE 6: Test suite - determinism verification
───────────────────────────────────────────────
SEVERITY: Important (contract verification)
FINDING: Tests were basic (2x determinism test)
FIX: Added test_determinism_100x() - runs 100 identical requests
     Verifies ALL 100 responses are IDENTICAL
RESULT: ✅ ADDED - strict determinism contract verified
